# Jashin-chan Dropkick

[← Voltar ao Workspace](../../README.md)

Este projeto é um **clone de alta fidelidade** e port moderno do site oficial do anime _Jashin-chan Dropkick (Dropkick on My Devil!!)_.

## 🎯 Objetivo

Replicar a experiência visual complexa do site original (estilização com ondas, patterns e assets flutuantes) utilizando uma arquitetura moderna, performática e tipada com Astro.

## ✨ Funcionalidades

- **🏗️ Arquitetura Data-Driven:** Dados de personagens, episódios e links centralizados em TypeScript.
- **🖼️ UI de Alta Fidelidade:** Replicação de elementos visuais complexos como divisores de onda e backgrounds dinâmicos.
- **📑 Sistema de Abas:** Implementação personalizada para seções de "Business Info" e "Discografia".
- **🎥 Galeria de Mídia:** Grid responsivo para trailers e conteúdos do YouTube.
- **⚡ Performance:** Transições suaves de página usando `ClientRouter`.
- **📱 Responsividade:** Tabelas de transmissão e menus otimizados para mobile.

## 🛠️ Tecnologias Utilizadas

- **Astro** (Framework principal)
- **TypeScript** (Tipagem de dados e lógica)
- **SCSS** (Estilização avançada e mixins)
